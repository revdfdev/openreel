# Bundled font: Muli

`app/src/main/res/font/muli_*.ttf` is Muli by Vernon Adams / Jacques Le Bailly,
licensed under the SIL Open Font License 1.1, which permits bundling and
redistribution. Muli is now published as "Mulish" on Google Fonts.

MX Player uses Muli as its UI typeface (`@font/font_muli` 15sp regular,
`@font/font_muli_semibold` 14sp), so matching it is a large part of what makes
the browse UI read as 1:1 rather than "a Material app with similar colours".

Upstream: https://fonts.google.com/specimen/Mulish/about
